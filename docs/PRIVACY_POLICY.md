# YouShop Privacy Policy

The policy text lives at
[`services/api/internal/legal/privacy_policy.md`](../services/api/internal/legal/privacy_policy.md).

That file is the canonical copy because it is the one the API actually
embeds and serves at `GET /privacy` — the public URL given to the Play
Console listing. Keeping a second copy here would let the published policy
and the documented policy drift apart, so this file is a pointer rather
than a duplicate.
